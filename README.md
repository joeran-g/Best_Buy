-----Welcome to my shopping console----

first you need to make sure you have installed all Packages from the requirements.txt.
check the import from main.py, based on the version, there could be differences.

for now there is a fixed shopping list, but you could give the function start() a dictionary of items
    in the format of '.ProductClass(name, price, quantity)', 
    for other formats, check the Products class and its child Classes.

to start, run main.py, 
or type "cd Best_Buy" and "python3 main.py" ("python main.py" on windows)
